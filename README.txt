# MUCI — Website Print & Foto Copy

## File
- `index.html` — halaman utama + SEO/preview WhatsApp
- `style.css` — desain responsif
- `script.js` — tombol pemesanan WhatsApp
- `images/muci-preview.jpg` — gambar preview link

## Yang wajib diganti
1. `script.js`: ubah `NOMOR_WHATSAPP`.
2. `index.html`: ubah `DOMAIN-ANDA` pada `og:image` dan `og:url`.
3. Ubah harga contoh.
4. Ubah alamat dan jam buka.
5. Jika punya domain sendiri, masukkan domain tersebut.

## Catatan upload file
Versi ini menggunakan hosting statis. Form tidak meng-upload file ke server. Setelah WhatsApp terbuka, pelanggan melampirkan file secara manual di WhatsApp.

## Publikasi
Website bisa dipasang di GitHub Pages. Upload semua file/folder ini ke repository dan aktifkan Settings > Pages > Deploy from a branch > main > /(root).
