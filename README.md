# MUCI — Website Print & Foto Copy

Website resmi percetakan dan toko alat tulis kantor (ATK) **MUCI** di Muara Enim.

---

## 📁 Struktur Berkas

* `index.html` — Halaman utama web (HTML & layout).
* `style.css` — Berkas styling desain antarmuka.
* `script.js` — Logika pemesanan WhatsApp & interaktivitas.
* `images/` — Aset gambar dan banner preview.

---

## ⚙️ Petunjuk Konfigurasi

Sebelum mempublikasikan atau menggunakan website, sesuaikan parameter berikut:

1. Buka berkas `script.js`.
